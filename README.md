# Finanças – Caio e Kauhan

App (PWA) de controle financeiro da casa: entradas, gastos, cartões, investimento, previsão e 13º.

- Hospedagem: GitHub Pages
- Dados e login: Firebase (Firestore + Authentication com Google), projeto `financas-casa-4de3b`
- Só os e-mails listados em `config.js` e nas regras do Firestore têm acesso aos dados.

## Instalar no celular
- **iPhone:** abra o endereço no Safari → Compartilhar → Adicionar à Tela de Início.
- **Android:** abra no Chrome → menu ⋮ → Instalar app.

## Backup
Contas → 🗄️ Backup → Baixar backup. Para restaurar, use "Restaurar de um arquivo".
